# DPAPI: Windows Data Protection API for Racket

This library provides a Racket interface to the Windows Data Protection API
(DPAPI), enabling secure encryption of sensitive data using Windows credentials.

**Documentation is at <https://joeldueck.com/what-about/dpapi>.**

Requires Windows Vista or later and Racket 8.0 or later. This library has been
tested on Windows 11 / x86_64.

```bash
raco pkg install dpapi
```
